# Five Hundred 游戏规则与变体说明书

版本 1.0　核实日期 2026 年 11 月 4 日

用途：为 500 项目的规则引擎、玩家接口与 bot 对战提供规则依据。本文说明吃墩游戏 Five Hundred，不涉及 Rummy 500。本文是对公开资料的独立整理，不是任何协会颁布的统一赛规。

**核心结论：不能用 Australian、American、Canadian 这样的名称唯一确定规则。必须同时声明人数、牌组、叫牌过程、特殊定约、Joker 规则、计分与终局条件。** 地区名称适合用作预设标签，实际裁决应由一份完整配置决定。

本文以一套明确的澳式四人参考玩法讲解完整流程，再列出其他地区、人数和桌规的差异。标注“项目约定”的内容是为消除实现歧义提出的选择，并不声称所有当地玩家都如此玩。正文中的 [S1] 等编号对应文末可访问的来源。

## 1 证据范围和命名

### 1.1 如何理解来源

| 来源类型      | 能证明什么          | 使用限制              |
| --------- | -------------- | ----------------- |
| 游戏运营方的规则页 | 该平台公开支持的玩法和选项  | 不能据此推断整个国家的统一玩法   |
| 专门规则汇编    | 不同地区及投稿者所记载的桌规 | 仍需保留地域、投稿和版本范围    |
| 专门玩家网站    | 作者采用的规则及约定     | 不等于赛事主管机构         |
| 百科和一般规则网站 | 查找线索、比较术语与表格   | 孤立记载或缺乏来源的细节应降级处理 |

优先核对了 Pagat、Trickster、NeuralPlay、Board Game Arena 等资料。Pagat 明确承认澳式规则没有普遍接受的唯一版本；运营方之间也存在可核实的差异。[S1–S4]

### 1.2 主要规则族

| 规则族                         | 有辨识度的特征            | 本文处理        |
| --------------------------- | ------------------ | ----------- |
| 澳式四人                        | 43 张牌、多轮竞叫、固定对家    | 完整参考流程      |
| 美式单轮                        | 每人一次叫牌机会，常带 Inkle  | 与澳式逐项比较     |
| 新西兰相关桌规                     | 可见重新竞叫、改变定约后重开等选项  | 不视为独立统一标准   |
| St Paul West Seventh Street | 45 张牌、5 张底牌、特殊叫牌约定 | 地方变体摘要      |
| St Paul Midway、Youngstown   | 固定副数、轮换搭档等赛事安排     | 地方赛事格式摘要    |
| 魁北克 Cinq-Cents              | 双 Joker、6 张底牌、独特计分 | 独立规则族摘要     |
| 2、3、5、6 人                   | 手牌分配、队伍和计分对象改变     | 单独说明，不只修改人数 |

以上均是有文献记载的规则族或实现，不代表穷尽所有家庭桌规。[S1–S4、S7、S10]

| Trick                          | 墩        | 各参与者按顺序各出一张牌后裁决的一轮     |

| Right Bower                    | 右 Bower  | 将牌花色的 J                |
| Left Bower / Off Jack          | 左 Bower  | 与将牌同色、另一花色的 J          |

Nullo 和 Misère 常对应同类目标，但名称相似不保证分值、叫牌位置或操作完全相同。[S2、S5]

## 3 澳式四人参考玩法

本章定义项目参考配置 `AU_4P_REFERENCE_V1`。它选择一种有资料依据的澳式玩法；与资料中不同的其他澳式桌规见后文。

### 3.1 人数 座位和牌组

四人组成两个固定队伍，对家同队；发牌、叫牌和出牌顺时针。

43 张牌的组成如下：

| 花色    | 使用牌                    | 张数  |
| ----- | ---------------------- | ---:|
| 红桃 ♥  | 4、5、6、7、8、9、10、J、Q、K、A | 11  |
| 方块 ♦  | 同上                     | 11  |
| 黑桃 ♠  | 5、6、7、8、9、10、J、Q、K、A   | 10  |
| 梅花 ♣  | 同上                     | 10  |
| Joker | 一张                     | 1   |

从普通牌中去掉所有 2、3 和两张黑色 4，再加入一张 Joker 即可。每人 10 张，底牌 3 张。[S2、S5]

### 3.2 发牌

第一位庄家随机确定，此后每副顺时针轮换。常见分包方式是每人 3 张、底牌 1 张；每人 4 张、底牌 1 张；每人 3 张、底牌 1 张。底牌朝下，不在叫牌阶段公开。[S11]

项目约定：全员 Pass 也算一次已完成的发牌，分数不变，由下一位庄家重新发牌。固定初始牌测试应保留实际牌序，不能只保留“3、4、3”这样的分包名称。

### 3.3 普通叫牌

庄家左手先行动。普通叫牌由 6～10 的墩数与 ♠、♣、♦、♥、NT 之一组成。承诺的是**本队合计至少拿到该数量的墩**。

参考配置中，普通叫牌先比较墩数，同墩数按以下次序比较：

`♠ < ♣ < ♦ < ♥ < NT`

例如 7♣ 高于 7♠，7♠ 又高于所有六阶叫牌。每次有效加叫都必须高于当前最高叫牌；否则只能 Pass。Pass 后本副不得重新加入。除最高叫牌者外所有人退出后，定约确定；最高者不能再自行改变定约。[S4、S6]

这里的花色次序用于叫牌，不表示打牌时所有红桃都能压所有方块。出牌的比较取决于领出花色及本副将牌。

### 3.4 特殊叫牌

| 定约          | 成功目标          | 参考分值 | 参考叫牌位置       | 资格         |
| ----------- | ------------- | ----:| ------------ | ---------- |
| Misère      | 定约者零墩         | 250  | 7NT 与 8♠ 之间  | 本副此前有人叫过七阶 |
| Open Misère | 定约者零墩，并按时公开手牌 | 500  | 10♦ 与 10♥ 之间 | 可直接开叫      |

两者均无普通将牌花色；定约者搭档停打。Open Misère 在第一墩完成后公开定约者余下手牌。上述叫牌位置有资料依据，但不是所有平台的默认值。[S6]

因此，在此配置中：

- 7NT → Misère：合法。
- 6♥ → Misère，之前没有七阶：不合法。
- Misère → 8♠：合法，虽然 240 小于 250。
- 10♦ → Open Misère → 10♥：均合法，后两项的分值同为 500。

这些例子说明：特殊定约的**叫牌序位、结算分值、开叫资格**是三个不同概念。

### 3.5 取底和弃牌

定约者私下取入 3 张底牌，从 13 张中暗弃任意 3 张，使手牌回到 10 张。刚取得的底牌也可弃出。参考配置中普通定约、Misère 和 Open Misère 都允许取底。[S4、S6]

弃牌不参与出牌，也不自动公开给搭档或防守方。搭档停打并不把其手牌交给定约者。

### 3.6 有将牌的大小与跟牌

有将时，将牌从大到小排列为：

`Joker > 右 Bower > 左 Bower > A > K > Q > 10 > 9 > …`

Joker 与左 Bower 都属于将牌花色；左 Bower 不再属于牌面印刷的花色。其他牌按 A、K、Q、J、10……排列。[S7]

例：红桃为将时，J♥ 是右 Bower，J♦ 是左 Bower。此时：

- 领出红桃，只有 J♦ 而无其他红桃者，仍然必须跟出 J♦。
- 领出方块，持 J♦ 并不意味着能跟方块；若没有其他方块，可垫牌或将吃。
- 若既有普通方块又有 J♦，在方块领出时应跟普通方块，不能用 J♦ 违反跟牌义务。

以上是花色归属规则的直接应用。

### 3.7 每墩如何进行

定约者首攻。每人依顺时针出一张，能跟领出花色必须跟；缺门时可垫其他花色或将吃，没有普遍的“必须将吃”或“必须压过已有将牌”要求。墩中有将牌时最大将牌获胜，否则领出花色的最大牌获胜。赢家领下一墩。[S8]

四人普通定约每墩 4 张，共 10 墩；参考零墩定约跳过停打搭档，每墩 3 张，仍有 10 墩。

项目约定：所有十墩都打完再结算，即使定约成败已确定。后续可优化提前结束，但必须证明全部应计分数都已确定；“定约已失败”不一定意味着防守计分也已确定。

## 4 Joker 必须作为独立规则处理

### 4.1 无将不意味着 Joker 没有特殊能力

NT 中没有普通将牌花色，四门 J 恢复普通位置。Joker 是否归入某门、什么时候能打、领出能叫哪门，都需要另外约定。

参考配置采用下述“允许定约者预先命名”的方案。[S9]

### 4.2 参考方案

**情况 A：定约者持有 Joker 并在首攻前公开指定花色。** 此后它是该花色最高牌，应按该花色处理跟牌与胜负。它不是能压过任何花色的将牌。

例：指定 Joker 为梅花；别人领出方块，持有者无方块时可垫出 Joker。因为它是梅花而不是将牌，不会仅因“是 Joker”就赢下方块墩。这一结果来自已命名牌的花色归属。

**情况 B：未作预先命名。** 包括 Joker 不在定约者手中：

| 情境                             | 参考处理                   |
| ------------------------------ | ---------------------- |
| 别人领牌，自己有领出花色                   | 不得出 Joker              |
| 别人领牌，自己缺门，NT                   | 可出 Joker，也可垫其他牌        |
| 别人领牌，自己缺门，Misère 或 Open Misère | 必须出 Joker              |
| 合法跟出 Joker                     | Joker 赢墩               |
| 领出 Joker                       | 指定此前没有被领出的花色，其他人按该花色跟牌 |
| 四门都曾被领出                        | 非最后一墩不得领出 Joker；最后一墩例外 |

此方案中的“此前被领出”指该花色曾是某墩的领出花色，不是曾有人垫过该花色。[S9]

项目约定：最后一墩例外时，若领出 Joker，仍须附一个花色声明，可任选四门之一，以保证跟牌接口完整。资料只明确最后一墩可领，接口上的声明编码由项目在此固定。

### 4.3 其他已记载方案

以下是替代选项，不能全都叠加成默认规则：

| 差异轴         | 已记载选择                                 |
| ----------- | ------------------------------------- |
| Joker 领出选门  | 任意门／未领出过的门／持有者未曾显示缺门的门／仅最后剩一张时可领      |
| Joker 跟出    | 仅缺门／随时／该门首次领出或自己已无该门时                 |
| 零墩强制出 Joker | 开启／关闭                                 |
| 零墩中的大小      | 最高牌／最低牌                               |
| 双 Joker 顺序  | 平台须明确；Trickster 普通方案黑 Joker 高于红 Joker |

其中“该门未被领出过”和“本人未显示该门缺门”是不同条件。玩家可能在该门第一次领出时就显示缺门，也可能该门已领出多次而自己一直能跟。[S2–S4]

## 5 参考计分与终局

### 5.1 Avondale 普通定约表

| 所叫墩数 | ♠   | ♣   | ♦   | ♥   | NT  |
| ---- | ---:| ---:| ---:| ---:| ---:|
| 6    | 40  | 60  | 80  | 100 | 120 |
| 7    | 140 | 160 | 180 | 200 | 220 |
| 8    | 240 | 260 | 280 | 300 | 320 |
| 9    | 340 | 360 | 380 | 400 | 420 |
| 10   | 440 | 460 | 480 | 500 | 520 |

等价公式为 `V(n,s) = 100 × (n−6) + b(s)`，其中基础值依次为 40、60、80、100、120。[S12]

### 5.2 每副结算

| 结果                | 定约方                      | 防守方        |
| ----------------- | ------------------------ | ---------- |
| 普通定约完成            | 加定约分                     | 每个防守墩加 10  |
| 普通定约失败            | 减定约分                     | 每个防守墩仍加 10 |
| 普通定约全取十墩          | 定约分低于 250 时改得 250，否则照定约分 | 0          |
| Misère 成功／失败      | 加／减 250                  | 0          |
| Open Misère 成功／失败 | 加／减 500                  | 0          |

超额墩通常不额外奖励，除了表中的全取十墩规则。[S2、S6、S11]

自制结算例：

- 叫 7♥、得 8 墩：本队 +200，防守方 +20。
- 叫 8♣、得 7 墩：本队 −260，防守方 +30。
- 叫 6♠、得 10 墩：本队 +250，不是 +40，也不是 +290。
- 叫 9♦、得 10 墩：本队 +380，不再额外加 250。
- Misère 得 1 墩：本队 −250；参考配置中防守方不得因此加 90 或 10。

### 5.3 整场终局

参考配置：本队完成定约后总分达到或超过 +500，获胜；总分达到或低于 −500，落败。单靠防守墩分达到 +500 不获胜。[S1]

**“防守不能直接获胜”和“防守分封顶 490”不是同一规则。** 前者可以允许分数继续累计，后者实际限制记分。两种在后续叫牌失败后会产生不同分数。[S1、S11、S14]

本参考配置选择：防守分可继续累计，不封顶，但必须完成定约才能正向出局。项目约定在一副完整结算后判定终局；先处理一方达到 −500 的失败，再处理成功定约方达到 +500 的胜利。

例：A 由 480 靠防守获得 40 分成为 520，继续比赛；若下副 A 叫 6♠ 并完成，达到 560 后获胜。若采用封顶 490，则第二副前是 490，数值和风险均不同。

## 6 美式规则

### 6.1 最稳定的区别是竞叫过程

常见美式为每人只有一次叫牌机会。前两位叫牌者可用六阶 Inkle 表示牌力；后两位普通叫牌从七阶开始。Inkle 不能成为最终定约；没有真正叫牌时须按该预设的全员不叫规则处理。[S2、S5]

例如四人依次 `Inkle ♣、Pass、7♥、Pass`，即定约 7♥，不会绕回首位继续加叫。澳式多轮则可能继续竞争。

这会改变策略的信息量和行动空间，不能只把多轮竞叫的上限从“大”改成“一”而忽略 Inkle。

### 6.2 牌组和特殊定约并不统一

| 条目         | 有资料依据的差异                            |
| ---------- | ----------------------------------- |
| 牌组         | 43 张与 45 张版本均可见；45 张保留黑色 4，对应 5 张底牌 |
| 零墩名称       | 常称 Nullo；可能禁用                       |
| Nullo 序位   | 可固定在七阶与八阶间，也可按 250 分放在 8♠ 与 8♣ 间    |
| Open Nullo | 并非所有美式版本都有，不能因名称对应就自动启用             |
| 全员不叫       | 重发；另有无定约 NT、双方按墩计分的玩法               |
| 防守获胜       | 有允许靠防守分获胜的美式预设，也有要求完成定约的记载          |

来源分别说明了这些不同选择，不能把它们合称为唯一“美式标准”。[S2、S3、S7、S8]

### 6.3 美式 Joker 与零墩防守分

Pagat 所述美式 NT／Nullo 中，Joker 不预先归入某门；跟出需缺门，但不强制在缺门时打出。领出可选本人此前未显示缺门的花色。Nullo 中防守收益还可按定约者拿到的墩数计算，而不是按防守者拿到的墩数计算。[S1]

例：若按这种计分，定约者 Nullo 取得两墩，则定约方承受破约损失，防守方另有相应二十点收益；这与参考澳式中防守得零分不同。

### 6.4 美式命名不能替代终局配置

Trickster 的美式默认允许防守分触达目标获胜，并有“双队过线时定约方优先”选项；Denexa 的美式文章却要求完成定约才能获胜。Denexa 还把竞叫描述为三轮，与通常的美式单轮介绍不一致。[S3、S7]

处理原则：需要复制某平台时，按该平台的完整配置实现；需要研究地区玩法时，保留来源差异，不通过多数表决消除它。

## 7 地方玩法和赛事格式

### 7.1 St Paul West Seventh Street

该地方版本使用 45 张牌和 5 张底牌。可见 Ace–no face 规则：恰有一张 A、没有 J/Q/K/Joker 时可申请重发，由搭档同意；也有 Grand Nullo，让两个搭档都参加并争取全队零墩。[S1、S7]

Grand Nullo 与 Open Misère 不同：前者改变的是两位搭档的目标与参与方式，后者主要改变手牌公开情况。不同记载对 Grand Nullo 的序位存在冲突，不应只按 510 这个数值推断合法压叫。[S7]

### 7.2 St Paul Midway 和 Youngstown

Pagat 记载的 Midway 赛事按每轮 4 副进行，并轮换搭档，以累计个人分数决定名次，不在 ±500 时终止。Youngstown 记载采用 10 轮、每轮 4 副；低于十阶的定约若全取十墩，另奖 100 分，且不使用 Nullo。[S1]

因此，赛事格式至少有两个独立维度：一副牌如何计分，以及整个比赛何时结束、搭档何时轮换。

自制比较例：叫 8♣ 并拿十墩，参考规则计 260；Youngstown 奖励方式计 360。若误用“低分定约改计 250”，就无法复现当地赛事。

## 8 魁北克和加拿大规则

### 8.1 Cinq-Cents 规则族

法语资料记载一种四人 Cinq-Cents：46 张牌、保留四门 4～A，加两个可区分 Joker；每人十张，底牌六张。无色 Joker 高于彩色 Joker。单轮叫牌可从六阶开始，定约者取底后弃六张。[S10]

该资料的计分与参考澳式明显不同：成功则定约方得定约分，失败则对方得定约分；目标 1000。无将领 Joker 的选门限制也独特，只能叫定约者此前领过的门。[S10]

不宜把这条陌生的 Joker 限制推广到所有加拿大玩家；原文没有覆盖的“首墩就领 Joker”等边界，应补充规则后再作为可执行预设。

### 8.2 NeuralPlay Canadian 是另一完整预设

该平台的 Canadian 预设为：46 张牌、6 张底牌、单轮叫牌从七阶开始；关闭普通 Nullo，保留 Open Nullo；防守不收普通墩分，破约时取得定约分，比赛阈值为 ±1000。[S4]

它与上述法语记载并非一套：最低叫牌、特殊定约和负向终局均不同。因此“加拿大”应是规则族名称，不能只设一个 `canadian=true`。

## 9 不同人数

### 9.1 牌组与组织速查

| 人数  | 一种已记载的牌组            | 分配             | 对抗结构                |
| ---:| ------------------- | -------------- | ------------------- |
| 3   | 四门 7～A 加 Joker，共 33 | 每人 10，底牌 3     | 定约者对两名临时防守者，个人记分    |
| 4   | 43／45／46 张          | 每人 10，底牌 3／5／6 | 通常固定对家 2v2          |
| 5   | 普通 52 张加 Joker，共 53 | 每人 10，底牌 3     | 可独打或临时组队，个人记分       |
| 6   | 含额外点数牌的 63 张牌       | 每人 10，底牌 3     | 常见 3v3；也有平台支持 2v2v2 |
| 2   | 不存在唯一统一牌组           | 见下节            | 两名实际玩家可能各控制多个出牌位置   |

三人和六人的牌组可在 Trickster 说明中核对；五人见 Pagat；双人见 CatsAtCards。[S1、S2、S6]

### 9.2 三人

每人单独累计分数；普通定约按定约者本人的得墩数判断成败，两名防守者各按自己所得墩数取分。零墩定约没有固定搭档需要停打，三人照常参加。[S4]

项目必须额外选择：一人达到 −500 后，谁算获胜；多人同副过线时是否共享胜利。不能直接复用四人“两队互为胜负”的结果对象。

### 9.3 五人

一种有记载的玩法：定约者换底后叫一张牌找搭档，持有者暂不公开身份；也可声明独打。该记载中普通叫搭档时双方各承担半份定约分，独打承担全份；Misère 独打。[S1]

**但五人计分不能默认如此。** CatsAtCards 记载的另一方案中，六、七阶叫一位搭档，八阶以上可选两位搭档，且各成员记完整定约分；F.G. Bradley's 的摘要又写成定约者全份、搭档半份。[S6、S15]

这几种分配会导致完全不同的个人激励。必须完整记录：找搭档时机、可叫的牌、是否能叫自己持有或弃掉的牌、身份公开时机、各角色分值。不能用“叫搭档”四字包办。

### 9.4 六人

常见 63 张牌可按普通 52 张加四门 11、四门 12、红色 13 和一张 Joker 构成。额外点数牌低于人头牌、高于 10；适用花色普通顺序为 A、K、Q、J、13、12、11、10……；有将时仍先处理 Bower。[S2、S5]

Trickster 同时列出 3v3 与 2v2v2。后者有两支防守队，零墩时谁停打、每支防守队如何得分、同时终局优先级都要另定，不能机械照搬两队结算。[S3]

### 9.5 双人

已记载的双人结构至少有：

- **33 张牌加未用暗手**：按三人结构发出三手十张牌，第三手不看、不使用；两名玩家实际竞赛。
- **24 张缩减牌组**：每门 9～A，不用 Joker；每人十张，底牌四张。
- **43 张桌牌结构**：除每人十张暗手外，各有五叠桌牌，每叠一暗一明，另有三张底牌；这是每人控制暗手和桌牌的结构，不是单纯每墩两张。

前两种见 CatsAtCards，第三种见 Pagat 的双人段落。[S1、S6]

双人规则的资料质量并不一致。例如某在线双人页声称用 43 张、每人十张、底牌三张，却未在文字规则里交代余下二十张如何处理。这类摘要不足以单独构成实现规格。[S16]

## 10 可选规则目录

以下只说明存在何种差异；未选定整套组合前，不视为一套可执行规则。

### 10.1 叫牌

| 规则轴     | 可选做法                | 要同步定义             |
| ------- | ------------------- | ----------------- |
| 叫牌次数    | 单轮／多轮               | 每人机会与结束条件         |
| 普通起叫    | 六阶／七阶或更高            | 是否仍有 Inkle        |
| Pass 后  | 永久退出／允许重新叫／定约改变后才重开 | 用累计退出还是连续 Pass 判停 |
| 自加叫     | 禁止／他人 Pass 后可提高     | 是否重开其他玩家资格        |
| 全员 Pass | 换庄重发／原庄重发／无定约 NT    | 底牌使用、首攻、记分        |
| 庄家强叫    | 关闭／前三家不叫后庄家必须叫      | 特殊定约是否可满足强叫       |

Trickster、NeuralPlay、CardzMania 分别公开了其中多种选项，不能假设每个平台都支持全部组合。[S3、S4、S8]

### 10.2 特殊定约

| 差异轴       | 已见选择或例子                        |
| --------- | ------------------------------ |
| Misère 分值 | 210、230、250；BGA 另有降低至 130 的选项  |
| Misère 序位 | 固定在七、八阶间；或按分值                  |
| Open 分值   | 330、350、430、500、520 等不同记载      |
| Open 序位   | 可能在九阶前、十阶前、10♦ 后、10♥ 后，或最高位    |
| 明手时机      | 第一墩后公开是常见方案；不能只写“明手”而不写时点      |
| 是否换底      | 总允许／总禁止／只允许普通 Misère           |
| 搭档参与      | 停打／由定约者控制两手／双方都打的 Double Nullo |

这些不是可任意互换的同义词。尤其普通定约的 Slam、个人 Open Misère、全队 Double Nullo，目标、参与人数和信息结构都不同。[S3、S4、S6、S13、S18]

### 10.3 不同计分表

Avondale 表见第 5 章。NeuralPlay 还列出 Original 和 Perfect；但历史名称在网站之间并不一致，应保存表格本身。[S4、S6、S17]

下表以列序 `♠、♣、♦、♥、NT` 列出两套可核对的数值：

| 墩数  | NeuralPlay Original | NeuralPlay Perfect  |
| --- | ------------------- | ------------------- |
| 6   | 40、60、80、100、120    | 20、40、60、80、100     |
| 7   | 80、120、160、200、240  | 120、140、160、180、200 |
| 8   | 120、180、240、300、360 | 220、240、260、280、300 |
| 9   | 160、240、320、400、480 | 320、340、360、380、400 |
| 10  | 200、300、400、500、600 | 420、440、460、480、500 |

Wikipedia 的 Original 小节展示另一套表，且标注缺乏来源；本文不把它确认为原始官方表。[S17] 这是需要进一步寻找早期牌厂说明书才能解决的历史问题。

更换分值表时，还须决定是否改变叫牌序位。若按分值叫牌，九墩低花色未必高于八墩高花色；不能保留 Avondale 的层级比较代码而只替换计分数字。

### 10.4 防守和终局

| 规则轴       | 常见或已记载选择              |
| --------- | --------------------- |
| 防守墩分      | 总是记／仅破约记／不记           |
| 破约处理      | 定约方扣分／防守方获得定约分        |
| 零墩失败的防守收益 | 不记／按定约方取得的墩数记分        |
| 全取十墩      | 低分定约改计 250／另加 100／无奖励 |
| 正向终局      | 必须完成定约／防守也可过线         |
| 防守累计      | 不封顶／490 等上限           |
| 比赛长度      | ±500／±1000 或其他阈值／固定副数 |
| 同副过线      | 定约方优先／最高分优先／允许并列      |

Score All 的选项页及多个游戏运营方确认这些差异可独立出现；地方赛事的具体组合仍需按第 7 章限定。[S3、S4、S14]

## 12 平台应采用的明确裁决约定

本章均为项目设计建议，不冒充传统牌规。目的是使前述桌规能被唯一执行和测试。

### 12.1 每个规则预设必须填全的字段

| 类别   | 必填内容                         |
| ---- | ---------------------------- |
| 标识   | 预设 ID、版本、来源、偏离来源之处           |
| 牌组   | 每张实际牌，Joker 标识，重复牌比较规则       |
| 座位   | 人数、队伍、行动方向、停打者、临时搭档机制        |
| 发牌   | 暗手、明牌、底牌、未用牌的数量及去向           |
| 叫牌   | 行动类型、普通起叫、Inkle、特殊序位、门槛、结束条件 |
| 重新叫牌 | Pass 后资格、自加叫、是否重开            |
| 换底   | 谁取底、取多少、弃多少、是否限制可弃牌          |
| 出牌   | 首攻、有效花色、必须跟牌、Joker 领出与跟出     |
| 信息   | 每阶段谁知道哪些牌、何时公开、公开什么          |
| 计分   | 数值表、成功条件、全取奖励、防守收益、个人分配      |
| 终局   | 阈值、副数、结算时点、多人并列和冲突优先级        |
| 异常   | 非法动作、超时、崩溃、错误发牌如何裁决          |

“默认同澳式”只能用于人类说明；保存给引擎的配置必须把继承结果展开，避免母配置更新后悄悄改变旧比赛。

### 12.2 可见信息

普通暗手玩法中，玩家知道自己的手牌、公开叫牌、已出牌、分数与规则。只有取底者知道原底牌和自己的弃牌；停打搭档的手牌不因停打自动变成公共信息。公开定约按规定事件后才增加可见手牌。

项目建议保留完整公开历史，让 bot 自行推理。记录中的真实暗牌、未来牌序及发牌种子不得放进玩家观察。五人叫搭档时，裁判知道真实队伍不意味着定约者也知道搭档身份。

### 12.3 非法行为和技术故障

项目建议：越权出牌、未按有效花色跟牌、错误换底张数或使用过期动作，一律拒绝且不改变状态。超时、崩溃属于平台竞赛政策，单独制定，不从传统桌牌的露牌罚则推导。

传统实体牌桌还存在错发、越序、偷看底牌、露牌等罚则；本次未发现可跨全部规则族通用的罚则。若支持真人实体牌裁判，应另立赛事规程。法语 Cinq-Cents 资料中的具体罚则只适用于其所述体系。[S10]
