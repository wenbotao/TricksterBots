# Adapt-v2：加强在线学习力度

新增`Adapt-v2`（别名`adapt-v2`），保留`Adapt`及三阶段v1策略不变。仍为可配置规则版，保留完整搜索式叫牌；搜索预算和胜负效用不变。本轮没有训练模型，也没有扩大根节点搜索预算。

| 参数 | Adapt | Adapt-v2 |
|---|---:|---:|
| 叫牌证据幂 | 0.2 | 0.6 |
| 出牌证据幂 | 0.3 | 0.6 |
| 后验保护中原先验占比 | 16% | 4% |
| 衰减公式中旧后验指数 | 0.97 | 0.99 |
| 每玩家每副叫牌证据上限 | 2 | 4 |
| 每玩家每副出牌证据上限 | 2 | 4 |
| 学习用原始手牌假设数 | 8 | 16 |
| 根节点搜索样本 | 8 | 8 |
| 弃牌候选上限 | 12 | 12 |
| 改善门槛／标准误系数 | 8／0.75 | 8／0.75 |

更大的证据幂、更少的先验回拉和更多的证据机会，让观察更快影响后验；较弱的旧证据遗忘使学到的倾向保留更久。仍给所有模型保留非零概率；没有区分力的证据不会让初始先验漂移。关联的同副动作与不匹配的风格模型仍可能造成过度自信，不能据这些参数预先断言实战改善。

V2通过独立类及`frozen-profiles-v7.json`记录，不修改旧版本。它复用旧版的风格候选和可配置规则续演设施，改变的是学习参数。三阶段全部启用。模型仍只接收自身牌和公开信息，不知道测试中其他座位实际使用的bot类型。

## 验证

新测试验证：相同证据对V2后验的影响更大；风格改变后能反转；所有模型概率非零；无信息证据不造成漂移；六份规则均可执行和重放。

独立公开流检查使用3种脚本叫牌风格×2个新种子，每组120次，共720次机会；两个学习器看到同样公开动作，不接收演员实际手牌。演员只使用自己的手牌生成动作。六组中V2有五组的平均NLL更低，一组略高，原始数值见结果报告。

这些演员恰属于模型的三个风格族，不能把该结果外推到Random、搜索式Strong等真实bot混合池；而且学习强度与假设手牌数量同时改变，无法单独归因于一个参数。

## 最终采用20组行为对照

依据最新指示，采用与原实验相同的20组计划、种子2711001；新版、旧Adapt与Strong各20场。最初完成的60组扩样实验不混入本报告。新旧版本不替换默认。

[完整报告和首次同局面分歧](adapt-v2-divergence-20/REPORT.md)保存阵容、牌序、完整牌谱和每组首次行为差异。加强学习版13胜7负，旧版与Strong均14胜6负。509项回归测试通过。

复现：

```sh
dotnet run --project FiveHundredLab -c Release -- adapt-learning-check \
 --games 20 --seed 2711001 --out /tmp/adapt-v2-new
```

`Profiles.CreateForRules("adapt-v2",seed,rules)`可接入同一规则快照。
