# 五种正式 bot 的随机混合对战

日期：2026-11-05。源码提交：42b69e6。

共90场完整比赛，每30场汇报。Weak、Medium、Fast、Strong、Partner每个座位独立等概率抽取，允许同场重复；每个座位是新实例并使用独立bot种子。采用正式类的默认规则路径（未显式加载JSON），四人固定对家组队，原澳式默认规则。一次比赛包含多副牌，直到达到正负分终局。

胜率按座位参赛人次统计。同队共享胜负，同一种bot出现两次计两人次；分居两队时可在同场同时记胜和负。360人次来自90场相关比赛，不视为360次独立实验。未作独立试验置信区间，也不把小样本排名视为稳定强度结论。

## 复现与数据

- plan.json：预先固定的90场阵容、发牌种子、庄位和四个bot种子。阵容种子20261105，其他种子流20261106。
- metadata.json：规则快照、程序集SHA256、源码提交和执行参数。
- game-NNN.json：逐场阵容、胜负、副数、运行时间和异常字段。
- game-NNN.json.gz：完整隐藏牌、动作、计分等牌谱，供赛后复核。
- summary-030/060/090.json：三次本批与累计统计。
- replay-030/060/090.log：每批30场的裁判重放结果；胜负还与逐场结果文件对照。
- Runner.cs、Runner.csproj：本次临时实验运行器；若工作区路径不同，需调整项目引用路径。

每场上限1000次发牌；四路并发仅用于缩短等待，耗时不是单bot性能基准。实验未修改仓库策略或规则，也没有上传GitHub。
