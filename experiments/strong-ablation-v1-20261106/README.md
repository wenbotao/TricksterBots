# Strong / StrongPlus 独立消融与预算分配试验

本轮原计划在新种子块上执行80组配对、160场比赛。用户要求停止后，实际保留68组完整配对、136场，剩余24场未运行。旧Strong、StrongPlus-v1及其上一轮90场数据均不修改。

## 控制版本

[StrongAblationBot.cs](../../FiveHundredLab/Bots/FiveHundred/StrongAblationBot.cs)保存各控制的策略逻辑，接受独立profile、种子、规则参数；没有任意修改旧bot的参数。

各profile注册为`strong-study-{简称}-v1`。base8需与原Strong逐动作等价，用于检查控制实现没有偷偷改变其他逻辑。所有控制均保留原Medium默认基准与续演。完整Plus额外使用Medium可见手牌适配变体及根节点零墩证明。

规则接口保留，但本文实战只使用默认路径。显式配置路径的叫牌仍是启发式，默认阈值组合不作用于该路径，不能把本轮结论外推到变体规则。

## 实战安排

| 组 | A方 | B方 | 配对数 | 目的 |
|---|---|---|---:|---|
| samples | all32 | 原Strong | 24 | 仅扩大采样的收益 |
| plus | StrongPlus-v1 | all32 | 16 | 同样本预算下完整强化包的附加收益 |
| wide | wide32 | all32 | 8 | 弃牌候选扩展 |
| threshold | tuned32 | wide32 | 8 | 固定门槛与标准误惩罚作为组合的变化 |
| bid-only | bid32 | all32 | 12 | 探索预算优先分给叫牌 |
| mixed | StrongPlus-v1+Medium | all32+Medium | 12 | 单bot替换的附加收益 |

纯队每方两个同类bot。每组两场相同发牌、庄位和座位bot种子，交换A/B队伍。全新种子块为`8326001 + pair*104729`；跨比较组共用相同pair种子，便于比较，不能把不同组结果合并成独立样本。每场200次发牌上限，截断不按领先方计胜。

所有组数量预先固定，不因中途胜负停止、加样本或调参。重点关注samples及plus两组，其余小组用于方向筛选。没有单独的Plus对tuned32实战，不能将各组胜率相加拆出组件贡献。

## 行为、统计与成本

17个可达体验局面×4个种子×9种版本，共612次查询。包含原Strong、7个控制和Plus。新建实例、相同观察和合法动作；检查返回合法性与体验要求。base8必须与原Strong全部相同。

每组以完整配对为统计单位，记录双胜/各胜一场/双负。提供整组bootstrap和保守区间，精确符号检验及Holm多重校正。不以没有显著差异证明等价；全是各胜一场时，也不将退化的bootstrap区间解释为没有总体不确定性。

保守区间：对配对双胜、双负的概率分别构造97.5%的Clopper–Pearson区间，再按`平均配对得分=0.5+0.5*(双胜概率−双负概率)`合成；由Bonferroni给出至少95%的同时覆盖，避免小样本零宽区间误导。

分阶段采样会改变后续随机流，所以同种子的整局分叉不等于仅当前阶段算得更准。相同输入的局部审计更适合定位直接动作变化，实战配对则衡量整个配置的结果。

并发比赛中的各阶段墙钟耗时只作诊断；相同样本预算也不代表相同耗时，Plus的可见手牌适配使用缓存。用于独立审计的耗时应在比赛结束后另测，不与并发审计混用。

## 文件与复现

`metadata.json`记录设计和策略源码指纹；`results/plan.json`为执行计划；各组目录保存逐场结果与压缩完整牌谱；`results/audit.json`为同局面查询。`summary.json`由`analyze.py`复算。

```sh
dotnet run --project experiments/strong-ablation-v1-20261106/Study.csproj -c Release -- /tmp/ablation-new matches
dotnet run --project experiments/strong-ablation-v1-20261106/Study.csproj -c Release -- /tmp/ablation-new audit
```

请使用新输出目录，不覆盖已有比赛。程序在已存在逐场结果时明确拒绝覆盖。612次审计也可独立重跑，但其输出会覆盖同名audit.json；保留原结果后再操作。

“同预算”在本轮仅指每个候选共用的隐藏牌样本数相同。候选数、续演次数和墙钟成本仍可能不同，结果表分别列出这些设置，不宣称严格等CPU预算。
